# Official source provenance

The complete `upstream/` reference snapshot comes from Dodo Payments' official MIT-licensed [checkout demo](https://github.com/dodopayments/dodo-checkout-demo/tree/ef7cbd980d8f1e57b036dc2af71ff05521b6175a), pinned to `ef7cbd980d8f1e57b036dc2af71ff05521b6175a`. Copyright (c) 2025 Tremor Labs, Inc. Both LICENSE.md copies preserve the MIT notice. Upstream was not modified or published.

Downloaded official recursive tree and textual blobs through `gh-axi`. The wrapper failed twice on binary `public/images/dodo.png`. Firstmate steering 001 authorized ordinary HTTPS download of the exact official [codeload archive](https://codeload.github.com/dodopayments/dodo-checkout-demo/tar.gz/ef7cbd980d8f1e57b036dc2af71ff05521b6175a). Archive SHA256 `dff9dc74eb0c849f15a33ab4603435aecccc3853b0d193d22ce06081f3b0fcf2`. Before extraction, every member was checked for the exact expected top-level, traversal/absolute paths and links. Extraction was confined to `dodo-target/upstream/`.

The runnable application in `app/` and `lib/` adapts the Special Downloads path. Its product name, one-time art-pack concept, twelve titles, hosted checkout flow and post-payment downloads derive from upstream `src/app/pricing/page.tsx` and `src/app/dashboard/page.tsx`. The official Special Downloads branch passes `confirm:false`, which is retained here. OAuth, subscriptions, credits and paid image generation are outside this minimal target.

The original source has unsigned webhook parsing and a return-page verifier that writes access. Those routes remain only in the non-executable reference snapshot. The runnable target replaces them with official SDK raw-body authentication, independent checkout/payment reads, idempotent order fulfillment through strict signed events or separately labelled session-owned API reconciliation, and a read-only entitlement oracle. Only `app/` is routed and built. `upstream/` is excluded from TypeScript and never served or run.

The local persistent SQLite adapter replaces upstream MongoDB for isolated synthetic accounts and one-time paid access. It retains the account/order/payment/download behavior, adds run ownership and reset isolation, and needs no remote database account. This is a target-app database, separate from Tryfolk's run database. It is a single-host local adapter, not a claim of MongoDB compatibility.

The runtime uses patched Next.js 16.4.0, React 19.3.0 and official Dodo TypeScript SDK 2.54.2. The reference snapshot remains at upstream Next.js 15.1.11/React 19.0.0. Locally authored sample artwork SVGs replace upstream Picsum placeholder downloads, avoiding external image dependencies. The samples do not assert the original pricing page's premium-art or 4096px claims.


Steering007 narrows future repairs to `lib/fulfillment-policy.ts`, the final grant/suppress decision shared by verified webhook and app reconciliation fulfillment. Payment verification, auth, ownership, ledgers, configuration and oracles remain outside the repair seam. `REPAIR-CONTRACT.md` and the machine `repair:contract` list the protected export and fixed regression commands. Controlled-fault tests remain baseline characterization; immutable repair regressions use labelled provider fixtures and require changed source with original broken configuration. No repaired-mode preset or provider baseline is shipped.
